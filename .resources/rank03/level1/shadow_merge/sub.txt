Assignment name: shadow_merge
Expected files: shadow_merge.py
Allowed functions: standard Python built-ins only
--------------------------------------------------------------------------------

Write a function py_shadow_merge(list1: list[int], list2: list[int]) -> list[int] that merges two lists of integers into a single sorted list, in ascending order.

The two input lists are not guaranteed to be sorted beforehand, and may contain duplicate values, which must be preserved in the result. Either input list may be empty.

For example:

py_shadow_merge([1, 3, 5], [2, 4, 6])
-> [1, 2, 3, 4, 5, 6]

py_shadow_merge([1, 2, 3], [4, 5, 6])
-> [1, 2, 3, 4, 5, 6]

py_shadow_merge([1], [2, 3, 4])
-> [1, 2, 3, 4]

py_shadow_merge([], [1, 2, 3])
-> [1, 2, 3]

py_shadow_merge([1, 1, 2], [1, 3, 3])
-> [1, 1, 1, 2, 3, 3]
