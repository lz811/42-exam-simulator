Assignment name: word_ladder
Expected files: word_ladder.py
Allowed functions: standard Python built-ins only
--------------------------------------------------------------------------------

Write a function word_ladder(start: str, end: str, sentence: list[str]) -> int that computes the length of the shortest transformation sequence from start to end, where each step changes exactly one letter and every intermediate word produced this way (other than start itself) must appear in sentence.

The returned length counts the number of words in the sequence, including both start and end (so if start equals end, the length is 1). All words are lowercase and the same length. If no such sequence exists, return 0.

For example:

word_ladder("hit", "cog", ["hot", "dot", "dog", "lot", "log", "cog"])
-> 5

word_ladder("hit", "cog", ["hot", "dot", "dog", "lot", "log"])
-> 0

word_ladder("same", "same", ["same"])
-> 1

word_ladder("cat", "cot", ["cot"])
-> 2
