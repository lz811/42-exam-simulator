Assignment name  : package_dependency_resolver
Expected files   : package_dependency_resolver.py
Allowed functions: standard Python built-ins only
--------------------------------------------------------------------------------------

Write a function:

def package_dependency_resolver(packages: dict[str, list[str]]) -> list[str]

"packages" maps a package name to the list of package names it depends on.
The function must return a valid installation order: a package must never
appear before any of the packages it depends on.

Rules:
- A dependency name that does not exist as a key in "packages" must be
  ignored (treated as already satisfied).
- Among all packages that are ready to be installed at the same time,
  they must be installed in alphabetical order (this makes the result
  deterministic, "wave" by "wave" of the dependency graph).
- If the dependency graph contains a cycle, so no valid order exists, the
  function must return an empty list.
- An empty "packages" dict must return an empty list.

For example:

package_dependency_resolver({"a": [], "b": ["a"], "c": ["a", "b"]})
-> ['a', 'b', 'c']

package_dependency_resolver({"a": ["b"], "b": ["a"]})
-> []

package_dependency_resolver({"a": ["x"]})
-> ['a']

package_dependency_resolver({})
-> []
