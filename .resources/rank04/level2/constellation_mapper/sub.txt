Assignment name  : constellation_mapper
Expected files   : constellation_mapper.py
Allowed functions: standard Python built-ins only
--------------------------------------------------------------------------------------

Write a function:

def constellation_mapper(stars: list[tuple[int, int]], size: int) -> list[str]

The function must build a square grid of "size" rows and "size" columns.
Each cell is represented by a single character: '*' if its (row, col)
coordinate appears in "stars", '.' otherwise.

The function must return the grid as a list of strings, one string per row,
read top to bottom, left to right within a row.

Coordinates in "stars" that fall outside the grid must simply be ignored.
Duplicate coordinates in "stars" have no special effect.

For example:

constellation_mapper([(0, 0), (1, 1)], 3)
-> ['*..', '.*.', '...']

constellation_mapper([], 2)
-> ['..', '..']

constellation_mapper([(0, 0), (0, 1), (0, 2)], 3)
-> ['***', '...', '...']
