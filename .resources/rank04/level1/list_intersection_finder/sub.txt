Assignment name  : list_intersection_finder
Expected files   : list_intersection_finder.py
Allowed functions: standard Python built-ins only
--------------------------------------------------------------------------------------

Write a function:

def list_intersection_finder(lists: list[list[int]]) -> list[int]

The function must return the sorted list of values that appear in every
single list contained in "lists" (duplicates removed).

If "lists" itself is empty, or if any of the inner lists is empty, the
function must return an empty list.

For example:

list_intersection_finder([[1, 2, 3], [2, 3, 4], [2, 5]])
-> [2]

list_intersection_finder([[1, 2], []])
-> []

list_intersection_finder([])
-> []

list_intersection_finder([[3, 1, 2]])
-> [1, 2, 3]
