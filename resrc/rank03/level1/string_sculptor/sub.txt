Assignment name: string_sculptor
Expected files: string_sculptor.py
Allowed functions: standard Python built-ins only
--------------------------------------------------------------------------------

Write a function py_string_sculptor(text: str) -> str that rebuilds the given string so that alphabetic characters alternate between lowercase and uppercase, starting with lowercase for the first letter encountered.

Whitespace characters are copied through unchanged and do not affect the alternation. Any other non-alphabetic character (digits, punctuation, symbols) is also copied unchanged, and likewise does not break the lower/upper alternation between the surrounding letters.

For example:

py_string_sculptor("hello")
-> "hElLo"

py_string_sculptor("Hello World")
-> "hElLo WoRlD"

py_string_sculptor("aBc123def")
-> "aBc123DeF"

py_string_sculptor("Python3.9!")
-> "pYtHoN3.9!"

py_string_sculptor("")
-> ""
