Assignment name: bracket_validator
Expected files: bracket_validator.py
Allowed functions: standard Python built-ins only
--------------------------------------------------------------------------------

Write a function py_bracket_validator(s: str) -> bool that checks whether every bracket in the string s is properly opened and closed in the correct order.

The string may contain the bracket pairs (), [] and {} mixed together with any other characters, which must simply be ignored. A string is considered valid only if every opening bracket has a matching closing bracket of the same type, and brackets are closed in the correct (nested) order.

An empty string is considered valid.

For example:

py_bracket_validator("()")
-> True

py_bracket_validator("()[]{}")
-> True

py_bracket_validator("(]")
-> False

py_bracket_validator("([)]")
-> False

py_bracket_validator("{[]}")
-> True

py_bracket_validator("hello(world)[test]{code}")
-> True

py_bracket_validator("((()))")
-> True

py_bracket_validator("((())")
-> False

py_bracket_validator("")
-> True
