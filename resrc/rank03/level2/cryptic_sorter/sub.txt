Assignment name: cryptic_sorter
Expected files: cryptic_sorter.py
Allowed functions: standard Python built-ins only
--------------------------------------------------------------------------------

Write a function py_cryptic_sorter(strings: list[str]) -> list[str] that sorts a list of strings using a three-level ordering: first by length (shortest first), then, for strings of equal length, alphabetically in a case-insensitive way, and finally, if both of those are still tied, by the number of vowels (a, e, i, o, u, counted regardless of case) the string contains, fewest first.

The original list must not be modified; a new sorted list is returned.

For example:

py_cryptic_sorter(["apple", "cat", "banana", "dog", "elephant"])
-> ['cat', 'dog', 'apple', 'banana', 'elephant']

py_cryptic_sorter(["aaa", "bbb", "AAA", "BBB"])
-> ['aaa', 'AAA', 'bbb', 'BBB']

py_cryptic_sorter(["hello", "world", "hi", "test"])
-> ['hi', 'test', 'hello', 'world']

py_cryptic_sorter([])
-> []

py_cryptic_sorter([""])
-> ['']
