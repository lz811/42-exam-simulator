Assignment name: base_converter
Expected files: base_converter.py
Allowed functions: standard Python built-ins only
--------------------------------------------------------------------------------

Write a function py_number_base_converter(number: str, from_base: int, to_base: int) -> str that converts the string number, expressed in from_base, into its representation in to_base.

Both from_base and to_base are integers between 2 and 36 inclusive. Digits above 9 are represented with uppercase letters A-Z, in the usual way. If from_base or to_base falls outside the 2-36 range, or number is not a valid representation in from_base, the function must return the string "ERROR" instead of raising an exception.

For example:

py_number_base_converter("1010", 2, 10)
-> "10"

py_number_base_converter("FF", 16, 10)
-> "255"

py_number_base_converter("255", 10, 16)
-> "FF"

py_number_base_converter("123", 10, 2)
-> "1111011"

py_number_base_converter("Z", 36, 10)
-> "35"

py_number_base_converter("35", 10, 36)
-> "Z"

py_number_base_converter("123", 1, 10)
-> "ERROR"

py_number_base_converter("G", 16, 10)
-> "ERROR"
