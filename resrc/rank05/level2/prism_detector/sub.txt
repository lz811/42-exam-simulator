Assignment name: prism_detector
Expected files: prism_detector.py
Allowed functions: standard Python built-ins only
--------------------------------------------------------------------------------

Write a function prism_detector(grid: list[str], pattern: str) that searches a rectangular grid of characters (a list of equal-length strings, addressed as grid[row][col]) for every occurrence of pattern read in a straight line starting from any cell, in any of the 8 directions (horizontal, vertical, and both diagonals, each forwards and backwards).

The function returns a list of (x, y, direction) tuples, one for every starting position (x = column, y = row) and direction where pattern is found in full without going out of bounds. The 8 direction labels used are: "H" (right), "H-" (left), "V" (down), "V-" (up), "D1" (down-right diagonal), "D1-" (up-left diagonal), "D2" (up-right diagonal), "D2-" (down-left diagonal). If grid or pattern is empty, return an empty list.

For example:

prism_detector(["ABCD", "EFGH", "IJKL", "MNOP"], "AFKP")
-> [(0, 0, 'D1')]

prism_detector(["ABCD", "EFGH", "IJKL", "MNOP"], "ABCD")
-> [(0, 0, 'H')]

prism_detector(["ABCD", "EFGH", "IJKL", "MNOP"], "AEIM")
-> [(0, 0, 'V')]

prism_detector(["ABCD", "EFGH", "IJKL", "MNOP"], "XYZ")
-> []
