Assignment name: graph_cycle_detector
Expected files: graph_cycle_detector.py
Allowed functions: standard Python built-ins only
--------------------------------------------------------------------------------

Write a function py_graph_cycle_detector(graph: dict[int, list[int]]) -> bool that determines whether a directed graph, given as an adjacency list mapping each node to the list of nodes it points to, contains at least one cycle.

Nodes that appear only as a value inside another node's neighbour list (and are not a key themselves) do not need to be explicitly visited as starting points; the search must still follow edges into them. An empty graph has no cycle. A graph with a single node and no outgoing edges has no cycle.

For example:

py_graph_cycle_detector({})
-> False

py_graph_cycle_detector({0: [1], 1: [2], 2: []})
-> False

py_graph_cycle_detector({0: [1], 1: [2], 2: [0]})
-> True

py_graph_cycle_detector({0: [1, 2], 1: [2], 2: []})
-> False

py_graph_cycle_detector({0: [1], 1: [0]})
-> True
