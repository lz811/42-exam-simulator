Assignment name  : array_rotation_detector
Expected files   : array_rotation_detector.py
Allowed functions: standard Python built-ins only
--------------------------------------------------------------------------------------

Write a function:

def array_rotation_detector(arr1: list[int], arr2: list[int]) -> bool

The function must return True if arr2 is a rotation of arr1, i.e. arr2 can be
obtained by taking some number of elements off the front of arr1 and putting
them back onto the end, without changing their relative order.

Two lists of different lengths can never be rotations of each other.
Two empty lists are considered rotations of each other.

For example:

array_rotation_detector([1, 2, 3, 4, 5], [3, 4, 5, 1, 2])
-> True

array_rotation_detector([1, 2, 3], [3, 2, 1])
-> False

array_rotation_detector([1, 1, 2], [1, 2, 1])
-> True

array_rotation_detector([], [])
-> True

array_rotation_detector([1, 2, 3], [1, 2])
-> False

Hints:
Think about what happens when you concatenate the array with itself.
